# Звіт по лабораторній роботі 28

## Мета роботи

Ознайомлення з десеріалізацією JSON у C# та побудовою моделей даних для роботи з комплексною структурою об'єктів.

## Завдання

- Описати класи для збереження інформації про автомобілі та виробників.
- Використати `System.Text.Json.JsonSerializer` для десеріалізації JSON-рядка у C#-об'єкти.
- Вивести загальну кількість автомобілів та перелік моделей з роком випуску і ціною.

## Опис реалізації

1. Створено JSON-рядок `jsonData`, який містить інформацію про 6 автомобілів.
2. Описано класи для десеріалізації:
   - `CarData` — кореневий об'єкт з полями `saved_at`, `total_count`, `cars`.
   - `Car` — опис автомобіля з полями `id`, `model`, `year`, `price_usd`, `body_type`, `color`, `mileage_km`, `is_new`, `manufacturer`, `engine`.
   - `Manufacturer` — дані виробника автомобіля.
   - `Engine` — технічні параметри двигуна.
3. У методі `Main` застосовано `JsonSerializer.Deserialize<CarData>(jsonData)` для перетворення JSON у модель.
4. Якщо десеріалізація пройшла успішно, програма виводить:
   - загальну кількість автомобілів;
   - для кожного автомобіля — модель, рік випуску та ціну в доларах.

## Структура класів

- `CarData`
  - `saved_at` — рядок часу збереження даних.
  - `total_count` — кількість автомобілів у масиві.
  - `cars` — список об'єктів `Car`.

- `Car`
  - `id`
  - `model`
  - `year`
  - `price_usd`
  - `body_type`
  - `color`
  - `mileage_km`
  - `is_new`
  - `manufacturer` — об'єкт `Manufacturer`
  - `engine` — об'єкт `Engine`

- `Manufacturer`
  - `id`
  - `name`
  - `country`
  - `founded_year`
  - `website`

- `Engine`
  - `displacement_cc`
  - `horsepower`
  - `torque_nm`
  - `fuel_type`
  - `cylinders`

## Висновок

Лабораторна робота 28 демонструє правильне моделювання JSON-структури у C# та базову десеріалізацію в об'єктну модель. Програма успішно виводить дані автомобілів, що дозволяє використовувати отримані об'єкти для подальшої обробки або фільтрації.
